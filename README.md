# Solichael Corporate Website

A responsive, single-page corporate website starter for Solichael. It uses plain HTML, CSS, and JavaScript so it is easy to understand and expand without adopting a framework immediately.

## Included

- Corporate introduction and about section
- Portfolio cards for VoltHub, Sleep & Home, and Agriculture
- Principles section
- Contact call-to-action
- Responsive mobile navigation
- Keyboard skip link and reduced-motion support

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Before publishing

1. Replace `hello@solichael.com` in `index.html` with the official email address you control.
2. Confirm the business descriptions and status labels are accurate. The page currently marks VoltHub as in development and Agriculture as a future opportunity.
3. Add your official phone number, address, registration details, and social links only if you want them public.
4. Consider adding a privacy notice if you later add forms, analytics, or customer data collection.

## Publish with GitHub Pages

1. Create a new GitHub repository named `solichael-website`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. GitHub Pages will show the published URL in the Pages settings when deployment completes.

This starter has no backend. The email button opens the visitor's email application; it does not submit a form or store enquiries.
